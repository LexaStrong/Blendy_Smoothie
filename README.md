# Blendy_Smoothie

A single-screen product landing hero for **Blendy**, a smoothie brand. Features a full-viewport product slider showcasing smoothie flavors with custom parallax wipes, floating fruit piece animations, and responsive controls.

## Flavours Included
- **Berry** (`#C2B0DC`)
- **Kiwi** (`#B4D58A`)
- **Banana** (`#F3DA8A`)
- **Strawberry** (`#F2AFC0`)
- **Apple** (`#B8DFB2`)
- **Orange** (`#F7C58A`)
- **Tropical** (`#F6CE84`)
- **Coconut** (`#E5DACB`)
- **Pineapple** (`#EAE18D`)
- **Tigernut** (`#DFC6A8`)

## Features
- **Pure Vanilla Web Stack**: Single HTML file with inline CSS and vanilla JavaScript; zero frameworks or build tools required.
- **Dynamic 2×2 Cut-out Sheet Processing**: Precision CSS background positioning and scaling of transparent PNG sheets for bottle and fruit assets.
- **Interactive Transitions**: Measured non-linear panel wipes with independent parallax factors for background text, bottle, shadows, and floating fruit pieces.
- **Idle Bobbing Motion**: Continuous fruit bobbing and rotation with randomized durations and phase offsets.
- **Responsive Design**: Scaling coordinate system with desktop, tablet, and mobile layouts.
- **Controls & Navigation**: Flavour tab navigation with gliding active underline indicator, next/prev arrow buttons, keyboard arrow navigation, touch/pointer swipe gestures, and autoplay.

## Getting Started
Simply open `index.html` in any modern web browser or serve it with any local static HTTP server.
